About OS LAB

ABOUT THE PROJECT

Operating System Laboratory

An interactive browser-based environment for understanding operating system algorithms.

What is OS LAB?

OS LAB transforms traditional operating system algorithm exercises into interactive simulations and visualizations.

Instead of only calculating results on paper, users can provide inputs, execute algorithms, observe system states, and analyze performance.
