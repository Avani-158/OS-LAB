How to Use OS LAB

Learn how to use the simulators and understand their visualizations.

1. Choose a Module

Select CPU Scheduling, Memory Management, or Page Replacement from the sidebar.

2. Provide Input

Enter your own data manually or generate a scenario automatically.

3. Run Simulation

Select an algorithm and run the simulation to observe its behavior.

4. Analyze Results

Study the visualization, metrics, and algorithm decisions.
